# بلوکستان (Blockestan)

بازی پازل بلوکی ۸×۸ با React، TypeScript، Tailwind CSS و Vite.

## ویژگی‌ها

- **حالت بی‌پایان (کلاسیک)**: بازی بدون محدودیت حرکت با ثبت رکورد و ذخیرهٔ خودکار بازی نیمه‌تمام.
- **کمپین ۶۰ مرحله‌ای**: ۶۰ مرحلهٔ دست‌ساز با هدف امتیاز، پاک‌سازی خط یا آزادسازی خانه‌های هدف و سقف حرکت.
- **چالش روزانه**: زمین مشترک آفلاین بر اساس تاریخ محلی (FNV-1a 64 + SplitMix64) با پاداش روزانه.
- **تقویت‌کننده‌ها و ادامه**: بازگشت حرکت (Undo)، تعویض قطعات (Swap)، چکش ۳×۳ (Hammer) و ادامهٔ بازی پس از شکست در صورت وجود مسیر نجات.
- **فروشگاه و پوسته‌ها**: ۴ پوسته (فیروزه‌ای، شب بنفش، آفتابی، روشن ساده) قابل بازشدن با سکهٔ مجازی.
- **ذخیره‌سازی محلی**: ذخیرهٔ نسخه‌دار و پشتیبان در `localStorage` همراه با افکت‌های صوتی و لرزش اختیاری.

## اجرای محلی

```bash
npm install
npm run dev
```

برنامه روی پورت `3000` اجرا می‌شود.
